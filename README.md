# Проект Resume: Мульти-средовая настройка

В этом проекте используются две отдельные Python-среды:
- **Среда приложения**: для запуска FastAPI веб-приложения и инференса.
- **Среда дообучения**: для дообучения модели RuBERT.

## 1. Клонирование и подготовка

Клонируйте репозиторий и перейдите в папку проекта:
```sh
git clone <ваш-репозиторий>
cd <папка-проекта>
```

## 2. Настройка сред

### Вариант A: Использование Conda (рекомендуется)

#### Среда приложения
```sh
conda env create -f environment-app.yml
conda activate resume-py311
```

#### Среда дообучения
```sh
conda env create -f environment-retrain.yml
conda activate resume-retrain-py39
```

### Вариант B: Использование venv + pip

#### Среда приложения
```sh
python3.11 -m venv .venv-app
source .venv-app/bin/activate
pip install -r requirements-app.txt
```

#### Среда дообучения
```sh
python3.9 -m venv .venv-retrain
source .venv-retrain/bin/activate
pip install -r requirements-retrain.txt
```

## 3. Использование

- **Запуск приложения:**
  - Активируйте среду приложения и запустите FastAPI сервер как обычно.
- **Дообучение модели:**
  - Активируйте среду дообучения и выполните `python retrain.py`.
  - Дообученная модель будет сохранена в `models/retrained_rubert` и может использоваться приложением.

## 4. Примечания
- Настраивать среды нужно только один раз на каждом устройстве.
- Если вы обновляете зависимости, повторно экспортируйте файлы зависимостей и закоммитьте их.
- В PyCharm можно выбрать нужную среду как интерпретатор проекта.
